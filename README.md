## What it does

`main.py` (Python 3.13, no dependencies) writes one sentence — the whole
entry — to `/output/entry.txt`. It is fully deterministic and offline: no
network, no API calls, no randomness, just a fixed string.

## The pitch (161 characters, one sentence)

> Tell make.fun your app idea in plain words and an AI agent will build the
> first version for you, free to try, so you can see it working before you
> spend a thing.

## Why this line

Eight candidates were drafted and judged locally with the Caffeine router
acting as the plain-spoken editor (persuasion first, then clarity, truth,
warmth/craft), in head-to-head pairs in both orders like the house judge.
This line won every pairwise game: it beats the warmest line (#7) 0.8–0.2
and the friend-analogy line (#3) 0.85–0.15, because it gives a non-coder a
concrete, low-risk reason to say yes now — free to try, see it working
before spending anything — in plain words with no overpromising.

## Run it

```sh
python3 main.py
cat /output/entry.txt
```
